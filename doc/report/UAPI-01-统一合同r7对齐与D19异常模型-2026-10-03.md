## 2. D19 迁移表

| 旧 | 新 |
| --- | --- |
| `TansrHttpException.Code == "<族码>"` 作主判 | `UnifiedApiException.Code`（19 统一码）主判，族码在 `Detail.DomainCode` |
| `DomainCode / DomainStatus / DomainRetryAction` 主读 | `Code / StatusCode / RetryAction` 主读；旧属性保留为桥接（无族事实时回落统一值） |
| `Code == "precondition_failed"` ⇒ rediscover | `RetryAction == rediscover`（`RequiresRediscovery`）或 `refresh`（`RequiresRefresh`） |
| 按族词 `backoff` 自行重发 | `UnifiedRetry.Advice(e).Replayable` → `RetrySameRequestAsync` 单次重放；`result_unknown` / `commit_unknown` 永不重放 |
| `CacheContinuityException.Code == "<族码>"` | `Code` 为统一码，族码 `DomainCode`，`Unified` 保存原异常 |
| 族直通 `TansrHttpException` | 保留；`Advice.Source == "domain"`，无动作位 `Stated == false` |

完整表与消费规则见 `CHANGELOG.md`、`README.md`「统一异常模型（D19）与三头调用」。新增公开类型：`UnifiedErrorCode`、`UnifiedRetryAction`、`UnifiedErrorReason`、`UnifiedErrorDetail`、`UnifiedRetryAdvice`、`UnifiedRetry`、`ApiCallOptions`、`ApiCallResult`、`UnifiedRequestHeaders`、`UnifiedCapabilities`、`UnifiedCapabilityClosure`；新增方法 `TansrClient.CallAsync` / `GetCapabilitiesAsync` / `GetCapabilityClosureAsync`。
