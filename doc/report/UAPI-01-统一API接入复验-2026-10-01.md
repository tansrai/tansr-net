## 4. 与 RFC / D18 / 错误映射 r3 的差异登记

1. **`tansr-schema-hash` 按域比较**：已修正为 discovery = 聚合、其余 = 主族源 SHA。SDK 仍只校格式不比值；比较留给调用方（`UnifiedResponseMeta.SchemaHash` + `ApiRoutes.DomainSchemaHash`），与 TS 参考客户端同策略。
2. **事件包络拒绝 `domain == "discovery"`**：比 schema 严；discovery 无 SSE 操作，不可达。不改。
3. **canonical 规范化入口**：C# 无独立 `decodeCanonical`，以 `Parse`+`EncodeControl` 近似，3 条数字字面分歧登记在 `NormalisingDivergences`（业务读取器按合同保留小数/指数字面）。
4. **金样未回放部分**：`Manifest`/`Capabilities`/`CapabilityClosure` 三类 56 向量无 C# 解码器，未回放（与上一批同）。
5. **错误映射 r3**：C# 不维护逐域码映射，无需改动；`resume_unavailable`/`cwd_unavailable` 由信封自述 `conflict` 409/`none` 解码，`DomainCode` 保留原族码。
6. **生成文件中的 `/v2` 文本**：仅第 277 行 `agent-session-v1` 族源注释 `packages/server/src/v2/contract.ts`，为 manifest 原文。
7. **旧前缀残留（非 SDK 源）**：`scripts/native-serve-consumer.mjs`、`scripts/native-media-ui.ps1`、`scripts/serve-integration.mjs`、`scripts/check-session-compatibility.mjs`、`examples/Shared/device-memory.md`、`src/Tansr.Sdk/*/Contract/`（vendored 参考材料）、`tests/Tansr.Sdk.Tests/Transport/test-framework-session.ps1`。属集成脚本 / 参考材料，待真实 Serve 可用后另批迁移。
